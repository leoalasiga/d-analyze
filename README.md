# 项目预算人员月度报工天数

本项目把自有员工和外包员工两份 Excel 转成可交互的 HTML 报工天数表。第一版只展示“项目预算人员月度报工天数”，后续统计表格按需要再补充。

## 使用

```bash
npm install
npm run dev
```

打开终端显示的本地地址，上传：

- 自有员工 Excel：结算周期为本年 1 月 1 日至 12 月 31 日
- 外包 Excel：结算周期为去年 11 月 1 日至今年 10 月 31 日

页面生成报工天数表后，可以导出一份独立 HTML。

## 生成当前样例报告

```bash
npm run sample
```

默认读取本机企业微信缓存里的自有员工和外包报工明细，输出到 `reports/项目预算人员月度报工天数.html`。

也可以指定文件：

```bash
npm run sample -- /path/to/自有员工.xlsx /path/to/外包.xlsx reports/report.html
```

## 分析口径

- 项目：优先使用 `所属立项项目`，其次使用 `关联立项`
- 人员：优先使用 `人员姓名`，其次使用员工姓名、姓名
- 属性：自有员工 Excel 统一按自有展示，外包 Excel 统一按外包展示
- 天数：按 `总工时(h)` 或 `总工时` 除以 8 折算
- 成本：自有员工按 2000 元/人天计算；外包按 Excel 中的 `单价` 乘以折算天数计算
- 月份：表格展示去年 11 月、去年 12 月和本年 1 月至 12 月，避免外包结算周期与自有员工本年周期混淆
